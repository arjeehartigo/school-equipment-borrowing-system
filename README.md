# School Equipment Borrowing System

A Flask + MySQL web application for managing school equipment borrowing and returning.  
This system allows students to borrow equipment, track due dates, and lets admins approve, reject, or mark items as returned/overdue.

## 🚀 Features
- User authentication (login/register)
- Borrow equipment requests
- Admin dashboard for approvals
- Return equipment management
- Reports & analytics (Borrowed, Returned, Overdue)
- Flash messages for feedback

## 🛠 Tech Stack
- **Backend:** Flask (Python)
- **Database:** MySQL (via `mysql.connector`)
- **Frontend:** HTML, CSS, Bootstrap
- **Templates:** Jinja2
